## 重建步驟

```bash
# 1. 授權並下載（Adobe MCP: asset_license_and_download_stock）
#    回傳的 S3 presigned URL 有效期 1 小時
curl -sSL -o stock/<ID>.mov "<presigned-url>"
```

```bash
# 2. 裁成直式 9:16。素材都是 16:9，直接裁會切掉人，
#    所以主畫面等比縮放置中、上下用放大模糊的同一畫面填滿。
FILTER='[0:v]crop=W:H:X:0[c];[c]split=2[bg][fg];
[bg]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=42,eq=brightness=-0.08[bgb];
[fg]scale=1080:-2:flags=lanczos[fgs];
[bgb][fgs]overlay=(W-w)/2:(H-h)/2[v]'

ffmpeg -ss <SS> -t <T> -i stock/<ID>.mov -filter_complex "$FILTER" -map "[v]" \
  -c:v libx264 -profile:v high -level 4.0 -pix_fmt yuv420p -crf 20 \
  -movflags +faststart -an "out/Q<NN>_<答案>.mp4"
```

`-map "[v]"` 是必要的 — 來源 .mov 帶一條 data stream，不指定就會被一起複製進去。
`-an` 確保沒有音軌。

## 已否決的素材

**499563095** — 標題寫 "Asian caregiver helping senior male from falling"，
實際內容是阿公全程癱在地上、照服員跪著急救。那是「跌倒受傷」不是「預防跌倒」，
而且遊覽車上玩遊戲放老人倒地，氣氛不對。已捨棄。

**教訓：素材庫標題會灌水，每一支都要下載看過才算數。**
縮圖 CDN（`t3/t4.ftcdn.net`）被這個執行環境的網路政策擋住，
Adobe 的 `asset_inline_preview` 端點也回 400，所以沒有便宜的預覽方式 —
一支就是 350MB 的完整下載。挑素材要保守。

## 這條路達成與未達成的

**達成**：真人、華人面孔、照服員淺藍上衣、動作清楚、無字幕、無音軌、9:16、5–15 秒

**未達成**：
- **不是台灣的家**。素材是泛亞洲攝影棚場景 — 沒有黑鐵窗、沒有米白磁磚、沒有大同電鍋。
  素材庫裡不存在台灣民宅的居服情境。
- 主畫面只佔直式畫面中間約四成高度（16:9 轉 9:16 的必然結果）。
- Q01 的照服員胸前掛著識別證，上面有極小的字。畫面縮到手機尺寸完全無法辨識，
  也不是答案，但嚴格說違反「畫面上不可出現任何文字」。
